# numtowords
My implementation where it converts numbers to words. There are many like this, but this one is mine.
```python
num_to_words(67) -- Output: sixty-seven
num_to_words(123) -- Output: one hundred and twenty-three
num_to_words(420) -- Output: four hundred and twenty
num_to_words(1_337) -- Output: one thousand, three hundred and thirty-seven
num_to_words(1_234_567) -- Output: one million, two hundred and thirty-four thousand, five hundred and sixty-seven
```
